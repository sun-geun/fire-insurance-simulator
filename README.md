# CARE-RING 화재보험 설계 시뮬레이터 — 웹·모바일 버전

기준 엑셀: `CARE_RING_화재보험_날짜8자리_추천색상통일_v9.xlsx`

신인 설계사가 업종·층수·건물자재·사용승인일·현장 질문을 입력하면 33개 담보의 **필수/권장/선택/인수불가/확인 필요** 상태를 자동 안내합니다.

## 주요 기능

- 주택·일반·공장물건 구분과 각각의 업종 목록
- 시설소유자배상책임 104개 원본 업종(시설코드 포함) 검색
- KSIC 11차 참고업종 1,202개 검색(메리츠 요율코드와 구분)
- 기둥·지붕·외벽으로 건물급수 산출, 주택 1·2급의 운전자상해보험 자동추천
- 면적·층수·출입구에 따른 다중이용업소·재난배상책임 진단
- 사용승인일 `YYYYMMDD`/`YYYY-MM-DD` 양식과 만 건축연한 자동 계산
- 20년 이상 주택 임대인배상책임/일반 급배수시설누출손해 인수불가 및 공장 급배수 인수불가 반영
- 주유기 대수·혼유방지기 설치대수·증빙 여부에 따른 주유소배상책임 안내
- 38개 현장 질문에 따라 추천보장 실시간 변경
- 담보별 쉬운 사고 예시, 질문, 인수 확인 문구 표시
- 휴대폰 화면 대응, 설계 결과 인쇄, 브라우저 로컬 임시저장

## 경고와 판정 범위

이 프로그램은 **신인 교육·설계 보조용**입니다. 고객에게 제공할 보험약관/인수 승인/보험료 견적이 아닙니다.

- 현행 메리츠 인수기준은 반드시 전산에서 재확인합니다.
- 법정 의무보험 분류의 시설별 신고·등록·용도, 상세 인허가 조건을 확인해야 합니다.
- 보험요율업종은 KSIC 코드만으로 확정하지 않습니다.
- 고객의 이름, 전화번호, 주민등록번호 등을 입력하거나 저장하도록 설계하지 않았습니다. 입력 설정만 해당 브라우저에 저장됩니다.

## 검증

`npm test`로 데이터 범위/날짜/급수/대표 추천담보 단위검사를 실행합니다.

별도 `tools/compare_to_excel.mjs` 검증은 원본 엑셀에서 30개 시나리오를 직접 다시 계산하고, 웹의 33개 추천상태·건물급수·추천상품·법정 진단 결과를 전수 비교했습니다. **30/30 일치**.

추가로 웹 브라우저 화면 조작, 특히 모바일 실기기에서의 시각검수는 공개 배포 전후에 확인하는 것을 권장합니다.

## GitHub Pages 배포

브라우저에서 직접 동작하는 정적 사이트입니다. 서버나 유료 API가 필요하지 않습니다.

1. GitHub에 공개 가능한 별도 저장소를 만듭니다. (예: `fire-insurance-simulator`)
2. `index.html`, `styles.css`, `app.js`, `engine.js`, `data.js`, `manifest.webmanifest`, `icon.svg`를 **저장소 최상위**에 올립니다.
3. `Settings → Pages → Build and deployment → Deploy from a branch`에서 브랜치 `main`, 폴더 `/(root)`를 선택합니다.
4. 페이지가 배포되면 `https://sun-geun.github.io/fire-insurance-simulator/` 형태의 URL로 PC·모바일에서 접속할 수 있습니다.

기존 실손 계산기 저장소 아래 `fire/`에 위 파일들을 올리면 `https://sun-geun.github.io/silson-calculator/fire/`와 같이 사용할 수도 있습니다.

**주의:** 공개 GitHub 저장소/Pages에 업로드하면 업종 데이터와 판정 규칙의 소스코드를 누구나 열람할 수 있습니다. 본사·회사 자료 기반 내용의 공개 가능 여부를 승인받은 뒤 업로드하세요.

## 폰트와 동작

Pretendard를 CDN에서 불러옵니다. 인터넷 없이 열 경우 시스템 폰트가 대신 사용될 수 있습니다. 엑셀의 담보 분류 및 색상 체계와 같은 빨강(필수)·주황(권장)·파랑(선택)·보라(확인)·진한 빨강(인수불가)을 사용합니다.
